# Security policy

## Supported versions

Security fixes are provided for the latest published version of FuProfile Unlocker.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private
security-advisory reporting feature for this repository. Include the affected version,
operating system, reproduction steps, expected impact, and any suggested mitigation.

Do not attach private photographs, account credentials, Adobe application files, or license
keys. A minimal synthetic or freely redistributable sample is preferred.

## Scope

Useful reports include unsafe file handling, unintended writes outside CameraRaw profile
directories, untrusted-path execution, dependency substitution, and installer or archive
integrity problems. General camera compatibility requests should use the normal issue tracker.
