# FujifilmCameraProfiles style data

- Upstream project: <https://github.com/abpy/FujifilmCameraProfiles>
- Upstream author: abpy
- Files used: the eight text files under `xml tables/`

- License URL: <https://creativecommons.org/licenses/by-nc-sa/4.0/>

FuProfile Unlocker uses the upstream LookTable and ToneCurve data to create camera-specific
DCP profiles. Redistribution and adaptations must retain attribution, remain non-commercial,
and use the same license. Photographs processed with the resulting profiles are not derivatives
of the profile data, as stated by the upstream project.

The upstream project describes the data as being based on Fujifilm Camera Matching profiles
available through Adobe Camera Raw / Lightroom. Its CC notice applies only to rights the
upstream licensor is able to grant; it does not grant Adobe or Fujifilm trademark rights or
represent endorsement by either company.

The upstream repository's `dcp examples/` directory is intentionally excluded because it
contains Adobe Standard profiles. FuProfile Unlocker does not redistribute Adobe DCP files.
